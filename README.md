# AttritionIQ — HR Analytics & Employee Attrition

AttritionIQ is an HR analytics project built to understand why employees leave an organization and how data can help HR teams make better decisions.

## 🎯 What I Worked On
- Analyzed employee data to understand attrition patterns.
- Explored factors such as overtime, salary, age, and job satisfaction.
- Built a machine learning model to predict potential employee attrition.
- Created interactive Power BI dashboards to present insights clearly.

## 🛠️ Tools & Technologies
Python, SQL, AWS S3, Snowflake, Pandas, Scikit-learn, SMOTE, Random Forest, Power BI, and Streamlit.

## 📊 Power BI Dashboard
- **Executive Overview:** Important HR metrics and attrition overview.
- **Attrition Drivers:** Factors related to employee attrition.
- **Risk Segmentation:** Employees with multiple risk factors.

## 🤖 Model Performance
- Accuracy: 64.1%
- Precision: 36%
- Recall: 31%
- F1-score: 0.33
